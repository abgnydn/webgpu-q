# Archived: `tools/run-phase-*.ts`

These were standalone `vite-node` CLI runners for producing the original Phase B–E publishable JSON artifacts (DMRG/Pfeuty-Bethe, LiH VQE, kernel-fusion sweeps, and the HF→CCSD(T) chemistry ladder). They predated the unified `experiments/` research harness and wrote artifacts directly to `experiments/results/<date>/level-N/` without the standardized `timedRun` sync, env capture, or pass-bar schema enforced by `experiments/lib/runner.ts`. Archived on 2026-09-04 because they are no longer referenced by `package.json` scripts, CI workflows, HTML, or TypeScript imports, and their functionality is superseded by the dashboard-driven `experiments/level-*` modules and the Playwright e2e benchmark suite. Historical behavior is preserved in git history under `archive/tools-run-phase/`.
