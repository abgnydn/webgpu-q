GPU-resident MPS · single-qubit gates phase 4a

Tensors live on the GPU between gate calls. A WGSL kernel mutates one site's tensor in-place per single-qubit gate — no CPU↔GPU round-trip between gates. Statevector readback at the end contracts all sites and compares against the CPU MPS. Two-site gates land in Phase 4b.

Full GPU two-site pipeline phase 4b · 5

Two-site gates routed entirely through the GPU: merge → in-place Jacobi SVD → column-norm reduction → permutation upload → extract-U + build-Tq+1 kernels. State stays GPU-resident across the whole circuit; only the final statevector is read back. Phase 5 lifts the square-SVD constraint by zero-padding the rectangular merged matrix to nMax × nMax, so circuits where χL ≠ χR mid-chain (deeper brick-walls) now run end-to-end.
